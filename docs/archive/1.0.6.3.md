# 1.0.6.3 需求与修改归档

## 需求

阅读项目，优化 Markdown 文档内 HTML 渲染；保持其他功能；审查并统一 macOS 与 Windows 前端交互，重点修复设置页面；发布 Windows/macOS 1.0.6.3；完成后归档并清理本地缓存及不必要文件。

## 实现

- 在现有 markdown-it/DOMPurify 渲染链路内补齐常用 HTML 展示属性及图片尺寸，不改变 Markdown 分块或代码块语义。锚点附着实际 HTML 节点，保留结构与滚动同步。
- 保留现有六组设置和保存/连接语义，统一表单外观、数字输入更新、分类切换、横向导航、动态吸顶高度和滚动条空间；修复 WebKit 长短分类切换横移。
- 现有浏览器回归扩展为 Chromium/WebKit 同流程；键盘测试使用平台适配的快捷键；新增真实输入 HTML 与设置交互回归。
- 发布流程在保存完成后再次检查图片上传状态；Playwright 发布、图片上传和自动更新回归改用真实状态/Promise 闸门，消除固定延迟与检查—执行竞态。
- CI 浏览器矩阵串行运行以适应托管机器冷启动；WebKit 源码边界和页面切换命中状态分别采用窄范围吸附与可逆离场状态修复。
- macOS 打包前执行完整 WebKit 检查；沿用双平台相同提交、SHA256、更新大小、Minisign 签名校验后集中公开发布的流程。
- 对外 `1.0.6.3` / 内部 `1.0.6+3` / MSI `1.0.6.3` / macOS bundle `1.0.603`。中英文下载入口、发布说明与更新记录同步整理。

## 验证与交付

详见 [验证记录](../validation-1.0.6.3.md)。修复提交 `cdbe357` 的 CI、Windows、macOS 与最终发布校验均成功；[v1.0.6.3](https://github.com/Bai-YB/hexo-lite-editor/releases/tag/v1.0.6.3) 已公开并设为 Latest，14 个远端资产经下载、SHA256、大小和更新签名复核通过。发布后已清除本开发目录约 7.68 GiB 的可再生构建与测试缓存。
