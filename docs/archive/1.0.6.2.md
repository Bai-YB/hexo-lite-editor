# 1.0.6.2 需求与修改归档

## 已确认的需求

简化文件同步和设置页面；完整同步文章、站点配置、链接导向与新模块，同时减少传输量；更新显示真实进度、摘要日志，下载与安装不打断写作；改善过渡并发布 1.0.6.2。

用户确认：完整源码增量同步、不同文件自动合并、网站手动发布、六组设置、默认手动下载、Windows 静默安装。

## 修改方案与落地

- **文件同步**：保留现有完整源码范围。首次无共同基线使用并集；已建立基线使用三方文件比较，保留各端独立修改，冲突逐项选择。后台任务不直接拉取覆盖正在编辑的内容。
- **传输与缓存**：复用捕获的字节快照；按 hash 更新缓存和 WebDAV 对象；进度显示真正需要传输的对象。修复 Windows 换行/Git 属性、被 .gitignore 忽略的站点源码、扫描失败和空项目基线。
- **同步页面**：状态及主操作、本次变化、四类范围、连接详情和高级操作分层；提供“发布网站”，说明同步与上线的区别。
- **设置页面**：常规、编辑器、图片、预览与发布、文件同步、更新与恢复；精简重复说明、保留偏好保存语义，连接即时生效，最近项目和恢复操作折叠。
- **更新页面**：默认静默检查、手动下载，增加百分比/字节/速度/预计时间、验证阶段、五条摘要与完整日志展开；完成后由用户点击安装。
- **动效**：页面短过渡、对话框自然缓动、进度条 transform 更新、减少动态效果支持。
- **版本发布**：`1.0.6.2` / `1.0.6+2`；双平台云端构建后集中验证并发布，源码、版本文档与发布说明一同推送。

## 接口和兼容

新增 `get_content_sync_summary` 返回分类文件数、源字节、相对成功基线的变化和删除统计；同步请求增加显式范围确认。同步清单 schema 保持兼容。

应用配置 schema 仍为 3，`update.autoDownload` 缺省为 false。更新状态增加 `verifying`，清单平台条目增加 `size`，旧客户端继续兼容。

验证结果、局限与发布流程见 [验证记录](../validation-1.0.6.2.md)。缓存只在发布完成后清理本开发目录内的已知生成项；源码、Git 历史、锁文件、配置、文档和用户项目资料保留。
