# 1.0.6.6 需求与修改归档

## 需求

1. 缩小 macOS 程序坞图标的视觉占比，与其他应用并排时尺寸协调。
2. macOS 小屏幕给编辑与即时预览留出更宽、更高的可用区域；打开窗口不超出显示器工作区域。
3. 同步模块文档、接口变动、版本说明，并补齐项目开发计划 1.0.6.3 至本版本的归档。
4. 恢复 Windows 与 macOS 双平台正式发布，更新清单同时包含两平台。

## 实现

- `scripts/generate-macos-icon.py` 从 `app-icon.png` 生成 88% 图案占比的透明画布和各尺寸 `.icns`；Windows `.ico`、应用内 favicon 与标题栏图标保持原资源。
- `src-tauri/src/lib.rs` 在 macOS 启动时按当前显示器工作区域调整最小尺寸，并仅在窗口超出工作区域时缩放、居中；保留已适配的恢复窗口位置。
- `EditorPage.svelte` 按工作区实际宽度切换 macOS 三栏、双栏和单栏；窄屏文章列表为覆盖侧栏，单栏可切换编辑与预览。切换布局不重建编辑器或预览、不修改保存的列宽与分栏比例。
- `EditorToolbar.svelte` 提供文章列表、单栏切换与专注模式入口；专注模式通过 `onFocusModeChange` 通知 `AppShell.svelte` 收起导航栏，工具栏和状态栏让出高度。小窗口次要操作仍可在高级菜单使用。
- Windows 编辑器布局保持原有行为；新增中文和英文按钮文案。

## 接口与配置

- `EditorPage` 新增内部组件回调 `onFocusModeChange(active: boolean)`；`EditorToolbar` 新增布局状态与切换回调。这些仅是前端组件接口，不新增 Tauri IPC、插件 API 或持久化配置字段。
- 既有 `layout.articleListWidth`、`layout.previewRatio` 与 `layout.previewVisible` 保持兼容；响应式显示状态不覆盖用户设置。
- 对外 `1.0.6.6`，运行时 `1.0.6+6`，Windows MSI `1.0.6060`，macOS bundle `1.1.3`。
