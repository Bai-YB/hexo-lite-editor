# 1.0.6.5 需求与修改归档

## 需求

解决长文档写作时编辑与预览的卡顿与主线程峰值；修复双向滚动互相干涉造成的错位与输入被打断；统一设置保存语义，消除"改了没保存"的困惑与保存按钮负担；重做深浅两套主题并对齐可访问性对比度；全站文案去 AI 味；文件同步设置日常状态过于冗长、GitHub/WebDAV 切换需要绕路关闭同步。

## 实现

- 预览渲染管线：`renderMarkdownPreview()` 输出交给 `previewBlocks.ts` 按顶层块拆分，与上帧指纹（`hashPreviewText`）比对后仅由 `previewSurface.ts` 替换变化块 DOM；`renderScheduler.ts` 用帧对齐 + 输入驱动的自适应节流合并连续编辑；含裸 HTML 块的文章按计划走全量渲染回退，安全优先。
- 滚动同步从双向改为单向：编辑器滚动驱动预览跟随；预览区滚动保持自由，不再回写编辑器位置；首尾仍按滚动范围直接对齐，锚点收集与迟到布局重测保留。
- 编辑器内部重构：`EditorSessionStore` 通道化分组通知（旧聚合订阅保留兼容），`EditorPage` 状态拆原子字段，`MarkdownEditor` 扩展改 Compartment 重组。
- 设置即时生效：删除草稿/保存控制器（`controller.ts`），改动 350 ms 防抖持久化；校验失败回滚到上次成功值、重选分区并聚焦字段；发布与图床操作前先冲刷未落盘改动；恢复默认立即写入；移除无效果的"图片插入方式"。
- 文件同步设置：三步规划卡与选择向导仅未启用时展示；启用态为状态卡 + 一行待上传摘要，统计细节收进默认折叠的"同步细节"；连接块顶部 GitHub/WebDAV 标签，选另一通道挂载其设置表单，预检通过后经 `enable_content_sync` / `enable_webdav_content_sync` 覆盖注册记录完成切换（旧通道数据不删除）。
- 主题：`tokens.css` 全量重写为浅色（暖纸 #faf9f6 级 + 墨绿强调）与深色（冷灰 + 钢蓝强调）两套 token；删除 CSS 内 `prefers-color-scheme` 复制块，"跟随系统"由 `AppShell.applyTheme()` 经 `matchMedia` 解析为显式 light/dark 并监听切换；features/pages/components/shell 四处样式文件的硬编码颜色全部 token 化。
- 文案：核心写作流、全局壳、周边页面四批改写，`uiMessages` 词条表同步收口（删除废弃保存语义与假设置词条，新增同步切换词条）；弹窗焦点恢复、Escape 抢占、危险操作确认、通知队列等五处交互修复。
- 对外 `1.0.6.5` / 内部 `1.0.6+5` / MSI `1.0.6.5` / macOS bundle `1.0.605`。

## 接口变动

- 对外接口零变动：Tauri 命令与事件、插件 API、AppConfigV3 配置文件格式均未增删改，新旧版本可互相升降级。
- 内部接口（前端）：`EditorSessionStore` 新增分组通道订阅、`subscribe()` 转兼容层；`features/settings/controller.ts` 删除；新增 `renderPreviewBlocks()`、`createAdaptiveScheduler()`、`previewSurface()`、`wordCount.ts`；`sourceLineForPreviewTop()` 降级为保留 API（反向滚动不再驱动）；`window.__previewStats` / `window.__editorStats` 仅 DEV 构建存在。
- 同步注册语义：跨通道切换复用平台既有 enable 命令（后端确认 enable 直接覆盖注册记录），未新增命令。
