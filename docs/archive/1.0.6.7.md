# 1.0.6.7 需求与修改归档

## 需求

1. macOS 程序坞图标进一步缩小，与其他应用并排时更协调。
2. macOS 小屏文章栏默认显示；用户可手动收起，展开时不遮挡编辑与预览。
3. Markdown 的六级标题和代码块在编辑区及预览区正确着色。
4. 审查前端、后端、依赖与右下角通知点击；完成双平台 1.0.6.7 发布。

## 实现

- macOS `.icns` 及预览图由同一生成脚本生成，图案占画布约 74%。
- `EditorPage.svelte` 让文章栏在 macOS 紧凑布局初次打开时默认显示，flex 独立列参与布局；手动收起状态不因窗口宽度变化重置，编辑/预览切换保持用户选择。Windows 三栏保持原有逻辑。
- CodeMirror 使用围栏语言数据支持，编辑区标题和代码采用明暗主题颜色；预览对 13 种已登记语言着色，未知语言与超长代码块保持转义，结果仍由 DOMPurify 清理。
- 插件网络响应改为逐块读取并在默认 5 MiB 限额处取消，避免响应头不含 `Content-Length` 时无界读取；更新锁文件中 Windows/macOS 使用的 Rust 安全修复版本。
- 右下角更新入口和任务详情按钮在 Chromium 与 WebKit 中验证了真实点击结果。

## 接口与版本

- 插件网络 API 的响应大小限制对调用方保持原有错误码 `plugin_network_response_too_large`；内部读取方式改变，模块说明见 [Plugin API](../plugin-api-reference.md)。
- 无新增 Tauri IPC 或持久化配置字段。`layout.articleListWidth`、`layout.previewRatio` 和 `layout.previewVisible` 保持兼容。
- 对外 `1.0.6.7`，运行时 `1.0.6+7`，Windows MSI `1.0.6070`，macOS bundle `1.1.4`。
