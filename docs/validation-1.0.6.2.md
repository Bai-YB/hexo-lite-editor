# Hexo Lite Editor 1.0.6.2 验证记录

对外版本 `1.0.6.2`；Cargo/Tauri/updater 内部版本 `1.0.6+2`；Windows MSI `1.0.6.2`；macOS 短版本 `1.0.6`、bundle `1.0.602`。

## 实现与验证

- 完整站点源码同步：首次并集、双机独立文件合并、同路径冲突、远端删除/本地修改冲突、空项目基线、Git 属性/换行、忽略规则和未跟踪缓存隔离均有 Rust 回归覆盖。
- 后台保存仅推送无冲突本地改动，发现远端变更后由用户点击合并；手动同步保留未保存保护。网页继续手动发布。
- 设置六组导航、同步范围摘要、即时连接状态、偏好保存、660px 单列布局有组件及浏览器验证。
- 更新使用共享状态、手动下载默认值、真实百分比、速度、验签阶段、五条发布摘要、无自动模态及点击安装；兼容旧配置缺少 `autoDownload` 字段。
- `pnpm check`：0 errors、0 warnings。
- `pnpm test`：29 个测试文件、157 项通过。
- `pnpm build`：生产构建成功；`pnpm audit --prod`：未发现已知漏洞。
- `pnpm test:e2e`：53 项全部通过（2 个 worker）；修正重复导航名称的定位器，并为并行环境的启动和模拟下载保留合理等待时间。
- `cargo fmt --check`、`cargo clippy --all-targets --all-features -- -D warnings`：通过。
- `cargo test --all-targets --all-features`：115 项通过，包含 44 项同步测试。
- impeccable detector：运行一次，结果为空。
- 视觉复核：1360×860 浅色、1120×720 深色、640×860 窄窗口，检查常规设置、同步未连接/已连接和更新就绪四类界面，共 12 张截图；无横向溢出。

## 发布流程

源码和标签推送后由 GitHub Actions 在 Windows/macOS 构建。两平台必须对应同一提交并全部成功，finalize 才下载资产校验 SHA256、manifest、tag SHA、更新包真实大小及 Minisign 签名，再上传三平台 latest.json 并正式发布。构建中的草稿不改变现有最新版本。

## 实际边界

- 浏览器使用 demo fixture 验证界面，Rust 使用本地双 Git 仓库和 loopback WebDAV 验证真实传输；依赖外部账号的测试无凭据时不访问用户服务器。
- 更新总大小优先使用 HTTP 长度，清单中的资源大小可作备用；均不可用或不一致时显示未知进度，不模拟百分比。
- 已下载包保留在进程内存，切换页面不丢失，退出后需重下；不包含断点续传。
- Windows 旧版 1.0.6.1 发起本次升级仍使用旧 passive 模式；新 quiet 模式用于本版之后的更新。系统授权弹窗无法由应用取消。
- 文件与目录同名互换若无法安全应用，会在写入前报告可恢复错误，保留本地数据；不自动删除未跟踪目录内容。
- 未在本机安装正式升级包；安装器烟测在云端 Windows 执行。macOS 未做 Apple 公证。
